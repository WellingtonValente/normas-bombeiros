# Política de Privacidade - Guia de Prevenção a Incêndios MG

Esta base é mantida para fins educacionais e técnicos, com consulta a documentos públicos de segurança contra incêndio e pânico em Minas Gerais.

## Dados tratados

Os arquivos publicados no GitHub Pages são estáticos e não coletam dados pessoais diretamente. O assistente pode receber informações fornecidas voluntariamente pelo usuário durante a conversa, como tipo de edificação, área, ocupação, município e dúvidas técnicas.

## Dados sensíveis

O assistente não solicita nem necessita dados pessoais sensíveis, documentos pessoais, dados médicos, financeiros, senhas, imagens íntimas ou informações sigilosas de terceiros.

## Finalidade

As informações fornecidas pelo usuário são usadas exclusivamente para gerar orientação técnica-educacional dentro do escopo de prevenção e segurança contra incêndio e pânico em Minas Gerais.

## Compartilhamento

A base estática hospedada no GitHub Pages não compartilha dados de usuários. O processamento da conversa ocorre na plataforma de IA utilizada pelo usuário, conforme os termos e políticas dessa plataforma.

## Limitações

As respostas do assistente não substituem profissional habilitado, análise técnica, laudo, projeto, ART/RRT, vistoria, aprovação do CBMMG ou interpretação oficial de órgão público.

## Contato

Para correções de conteúdo, atualização de base normativa ou remoção de algum material publicado indevidamente, utilize os canais oficiais definidos pelo mantenedor do repositório.
